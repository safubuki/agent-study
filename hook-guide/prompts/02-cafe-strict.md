架空のスペシャルティコーヒー店「KAME ROASTERY（カメ・ロースタリー）」のホームページを1枚作ってください。

## 内容

- コンセプト：「ゆっくり、深く、丁寧な一杯を。」自家焙煎の小さなカフェ＆ビーンズショップ
- 営業時間：10:00〜19:00（火曜定休）※現在の時刻から「営業中／準備中」を自動判定してバッジ表示
- メニュー：ハンドドリップ、エスプレッソ、季節の焼き菓子（タブ切り替えでフィルタ表示）
- 豆のこだわり：エチオピア・コロンビア・グアテマラの3種のカード（酸味・苦味・コクの5段階チャートつき）
- アクセス・店舗情報：架空の住所、最寄り駅からの案内、予約・問い合わせフォーム（送信確認モーダルつき）

## 見た目と動き・技術規約（厳守）

- 温かみのあるカフェらしい配色（深い焙煎ブラウン、クリーム色、テラコッタのアクセント）
- ライト／ダークモード切り替えボタン
- `<html lang="ja">` と `<meta name="viewport" ...>` を必ず入れる
- セマンティックタグ（`<header>`, `<main>`, `<footer>`）をすべて使う
- 配色は `:root` に CSS カスタムプロパティ（`--` で始まる変数）として定義して使う
- スマートフォン幅（〜480px）でも崩れないよう `@media` クエリを入れる
- ボタンやナビゲーションにはアクセシビリティ用の `aria-label="..."` を付ける
- **禁止事項**：
  - 外部 URL（`http://` / `https://`）の `<script>`, `<link>`, `<img>`（Google Fonts や外部画像サイトを含む）は一切使わない（イラストは CSS またはインライン SVG で表現）
  - HTML タグに直接 `style="..."`（インラインスタイル）を書かない（すべて `<style>` 内のクラスにする）
