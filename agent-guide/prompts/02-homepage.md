- 店名：こもれび珈琲（Komorebi Coffee）
- コンセプト：木漏れ日の入る小さな自家焙煎カフェ
- 営業時間：火〜日 8:00〜18:00（月曜定休）
- メニュー例：ブレンド 480 円、カフェラテ 550 円、季節のタルト 520 円、トースト 450 円 など 8 品程度
- 住所：架空の住所でよい

## セクション構成

1. ヒーロー（店名とキャッチコピー。背景はゆっくり動くグラデーション）
2. お店について（コンセプトの紹介文）
3. メニュー（「ドリンク／フード／スイーツ」のタブで絞り込み表示）
4. 営業案内（今日の曜日と現在時刻から「営業中」「準備中」「定休日」を自動表示）
5. ギャラリー（画像は使わず CSS で表現したカード。クリックでモーダル拡大）
6. お問い合わせフォーム（送信ボタンで入力チェックし、問題なければ「送信しました」と表示。実際には送信しない）

## 見た目と動き

- 少しオシャレで温かみのある雰囲気（例：コーヒーブラウンとクリーム色、手書き風ではない上品なフォント指定）
- スクロールすると各セクションがふわっと表示される
- 上部の固定ナビ。スマートフォン幅ではハンバーガーメニューになる
- ナビのリンクは滑らかにスクロールする
- スマートフォン幅（〜480px）でも崩れない
- 外部ライブラリ・外部画像は使わない（ブラウザでファイルを開くだけで動くこと）
