# 作業日誌（個人層）

> サンプル。実際は `~/.claude/skills/my-daily-log/` に置く。
> 製品リポジトリに同じ名前のスキルがあると、こちら（個人）が優先される。共有スキルと名前を重ねないこと。

1. 日誌ファイル `~/.claude/skills/my-daily-log/log.md` の末尾に `- YYYY-MM-DD: <1 行>` を追記する（無ければ作る）。
2. 「週のふりかえり」と言われたら、直近 7 日分を読み、できたこと・詰まったこと・来週やることを 3 行で返す。
