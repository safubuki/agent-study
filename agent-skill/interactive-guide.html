エージェントスキルの仕組み・階層化・運用ループ

エージェントスキルとは、SKILL.md を目次にして参考資料やスクリプトをまとめた「手順書つきの道具箱フォルダ」です。 同じスキルを Claude Code でも GitHub Copilot でも読み込めます（オープン標準 agentskills.io）。

STEP 3 — 全社・部署・案件を矛盾なく重ねる

「地図に重ねる透明シート」とコンデンサ C1（63 V）の判定体験

どんな場面？ 電源ユニットの回路図にあるコンデンサ C1（定格 63 V） をチェックします。 「全社（L1）」「部品の電圧仕様（L2：通常 24 V）」「電源係の基準（L3：定格の 70% 以下）」という透明シートが自動で重なります。ここに「特定案件だけの一時上書き（L4 付箋）」を貼ると何が起きるでしょう？
通常品と、ACME 社向け案件（/case-context 付箋）を切り替えて判定の変化を見ましょう
L1（全社シート）：安全基準と「上書きしてよい項目」を定義常時適用
L2（部品・ドメインシート）：power-unit の標準入力＝24 Vフォルダ一致で自動適用
L3（電源係シート）：コンデンサは定格電圧の 70% 以下で使う担当係ルール
L4（案件の付箋 /case-context）：ACME 社向けは入力電圧＝48 V に一時上書き未貼付
コンデンサ C1（定格 63 V）への負担率（基準：70% 以下）
