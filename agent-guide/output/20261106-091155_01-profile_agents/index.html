About

プロフィール

山田 太郎です。平日は社内エンジニアとして、Python での業務効率化ツールの開発や、社内向け Web サイトの制作に取り組んでいます。地味な仕事ですが、「これ、助かります」と言ってもらえる瞬間がいちばんのやりがいです。

週末はカメラを担いで山へ向かいます。登山と写真という二つの趣味は、気づけばひとつにつながっていました。早朝の澄んだ空気、ゆっくり色を変えていく空、稜線に差し込む光。その一瞬を持ち帰りたくて、シャッターを切っています。

帰宅後は RAW 現像で、その日に見た景色にできるだけ近づける作業を楽しんでいます。山頂で飲むコーヒーが一番おいしいと思っているので、荷物にはいつも小さなバーナーとドリッパーが入っています。
