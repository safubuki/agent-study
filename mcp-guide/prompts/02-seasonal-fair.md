# お題2：秋の収穫祭フェア 特設ランディングページ＆店長向け原価レポート

架空のカフェ「**Kame Cafe（カメカフェ** で開催する「**秋の収穫祭フェア（Autumn Harvest Fair** の特設 Web ページ（HTML / CSS / JS 一体型）を作ってください。

## ページに必ず載せる内容

1. **秋限定メニュー（`season: "autumn"`）全6品のショーケース**
   - カタログから**秋限定（`autumn`）のメニュー全6品**を漏れなく抽出し、商品ID・商品名・説明文・税抜価格・イートイン税込価格（10%）・テイクアウト可否（不可の商品は「店内飲食限定」バッジを表示）・カロリー・アレルゲン（コンタミ含む）を見やすく並べてください。
2. **秋の特別ペアリング3コースの価格＆店長向け原価率チェック表**
   - 次の3つの秋ペアリングについて、**セット割引（150円引き）適用後のイートイン税込価格・合計カロリー・原価率（%）・社内目標（原価率 35.0% 以下）の合否判定**を正確に計算して掲載してください。
     - **コース1（和栗づくし** `FD-005`（ローストかぼちゃとくるみのメープルキッシュ）＋ `DR-006`（和栗とほうじ茶のモンブランラテ）
     - **コース2（秋鮭グラタン＆りんご使用** `FD-004`（秋鮭と4種きのこの豆乳クリーム米粉グラタン）＋ `DR-007`（信州りんごとシナモンのホットサイダー）
     - **コース3（贅沢丹波栗パフェセット** `SW-004`（丹波栗と宇治抹茶のパフェ）＋ `DR-001`（深煎りカメブレンド）
   - ※ コース3は原価率目標（35.0%以下）を超えるかギリギリになる可能性があります。正確な計算結果にもとづいて合否バッジ（合格／基準超過）を表示してください。

## 見た目と動き（UI 要件）

- 秋らしい紅葉・和栗・琥珀色を基調とした上品なデザイン。
- 「お客様向けメニュー表示」と「店長向け原価・粗利チェック表示」をワンクリックで切り替えられるモード切替スイッチ。
- 各コースをクリックすると内訳（小計、セット割引 -150円、消費税額、原価合計、粗利額）がモーダルまたはアコーディオンで開く動き。
- スマートフォン幅（〜480px）でも崩れないレスポンシブ対応。
