# お題1：アレルギー安心ガイド＆おすすめペアリング Web ページ

架空のカフェ「**Kame Cafe（カメカフェ）**」の公式メニューデータをもとに、アレルギーをお持ちのお客様が安心してメニューを選べる**1枚のインタラクティブな Web ページ（HTML / CSS / JS 一体型）**を作ってください。

## ページに必ず載せる内容（数値の正確さが重要です）

1. **「小麦・卵・乳」の3つすべてを含まない安心メニュー一覧**
   - **重要**：原材料に直接含まれないだけでなく、**製造ラインの微量混入（コンタミネーション）にも「小麦・卵・乳」が含まれないメニューだけ**を厳選して掲載してください。
   - 各メニューには「商品ID・商品名・カテゴリ・税抜価格・イートイン税込価格（10%）・テイクアウト税込価格（8%）・カロリー・残っているアレルゲン（大豆・ごま・アーモンド・りんご等）」を正確に表示してください。
2. **おすすめの安心セット3組の価格・栄養シミュレーション**
   - 上で抽出した安心メニューの中から、次の3組のペアリングセットをつくり、**セット割引（150円引き）適用後の税抜価格・イートイン税込価格・テイクアウト税込価格・合計カロリー・社内向けの原価率（%）**を正確に計算してカード形式で並べてください。
     - **セットA（定番ランチ）**：`FD-001`（米粉フォカッチャサンド）＋ `DR-001`（深煎りカメブレンド）
     - **セットB（秋のご褒美カフェタイム）**：`SW-003`（紅はるかと米粉のスイートポテトタルト）＋ `DR-007`（信州りんごとシナモンのホットサイダー）
     - **セットC（濃厚ショコラ＆ハーブ）**：`SW-001`（米粉と豆乳のガトーショコラ）＋ `DR-005`（瀬戸内レモングラス＆ジンジャーハーブティー）

## 見た目と動き（UI 要件）

- カフェらしい落ち着いた温かみのあるデザイン（ダークモード切替ボタンつき）。
- アレルゲン絞り込みフィルタボタン（「乳なし」「卵なし」「小麦なし」「ノンカフェインのみ」などをポチポチ切り替えると、該当するメニューカードが絞り込まれる動き）。
- イートイン（10%）とテイクアウト（8%）の表示価格を一括で切り替えるトグルスイッチ。
- スマートフォン幅（〜480px）でも崩れないレスポンシブ対応。
