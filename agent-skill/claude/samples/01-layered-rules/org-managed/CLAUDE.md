# 全社共通の約束（サンプル：管理 CLAUDE.md）

> このファイルは agent-skill/claude/samples の説明用サンプルです。実際の運用では IT 部門が
> Windows: `C:\Program Files\ClaudeCode\CLAUDE.md` / Linux・WSL: `/etc/claude-code/CLAUDE.md`
> に配布し、利用者は外せません（`claudeMdExcludes` でも除外できない）。

## 必ず守ること（理由つき）

- 顧客名・個人情報を、コード・コメント・コミットメッセージ・外部サービスへの入力に書かない。
  理由：契約上の守秘義務。違反は事故として扱われる。
- 秘密情報（`.env`、鍵、トークン）は読まない・書かない・表示しない。
  → 管理設定の `permissions.deny` で機械的にも止めている（止められたら別の方法を探す）。
- 出荷判定に関わる数値（校正値・安全しきい値）は、人のレビューなしに変更しない。
  → 製品リポジトリの保護フックでも止めている。

## 書き方

- 文書・コメントは日本語。専門用語は初出で 1 行説明する。
