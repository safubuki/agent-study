# 組織のカスタム指示（サンプル：GitHub の画面に貼る文章）

> 組織のオーナーが GitHub の **Organization settings → Copilot → Custom instructions** に貼る文章の例です。
> ファイルとしてリポジトリに置くものではありません（このファイルは説明用）。

**効く範囲に注意**：組織のカスタム指示が使われるのは **GitHub.com 上の Copilot（Chat・cloud agent・code review）だけ**です。
VS Code・Copilot CLI などの**ローカルの画面では使われません**。ローカルでも効かせたい全社の約束は、
製品リポジトリの AGENTS.md / `.github/copilot-instructions.md`、またはフック（強制）にも書いてください。

（ここから下を貼る）

- 顧客名・個人情報を、コード・コメント・コミットメッセージ・PR 本文に書かない（契約上の守秘義務）。
- 秘密情報（`.env`、鍵、トークン）は読まない・書かない・表示しない。
- 出荷判定に関わる数値（校正値・安全しきい値）は、人のレビューなしに変更しない。
- 文書・コメントは日本語。専門用語は初出で 1 行説明する。
