## 要点

### 1. アーキテクチャとデータ層
- **JSON-RPC 2.0**：すべての通信メッセージは JSON-RPC 2.0 形式（要求 `request`、応答 `response`、通知 `notification`）でやり取りされる。
- **3つの役割**：
  - **Host**（ホスト）：AI アプリ本体（Claude Code、VS Code など）。複数の Client を管理し、セキュリティ権限やユーザーの同意を統括する。
  - **Client**（クライアント）：ホスト内部でサーバーごとに1つ作られ、1対1の接続を保つ。
  - **Server**（サーバー）：特定の機能・データを提供する独立プログラム。

### 2. サーバーが提供する3つの基本機能（Server Primitives）
| 機能 | メソッド名 | 誰が主導して使うか | 役割 |
|---|---|---|---|
| **Tools**（ツール） | `tools/list`, `tools/call` | **モデル主導**（Model-controlled） | AI が自分の判断で呼び出す関数（検索、計算、外部 API 実行、DB 更新など） |
| **Resources**（リソース） | `resources/list`, `resources/read` | **アプリ／ユーザー主導**（Application-controlled） | ファイルや DB レコード、設計書など、URI（`file://` や `memo://`）で指定して読み込む参考資料 |
| **Prompts**（プロンプト） | `prompts/list`, `prompts/get` | **ユーザー主導**（User-controlled） | スラッシュコマンド等から呼び出せる定型プロンプトのテンプレート |

### 3. クライアント側が提供する双方向機能（Client Primitives）
- **Roots**：ホストがサーバーに対して「どのフォルダや URI の範囲を触ってよいか」の境界を伝える仕組み。
- **Sampling**：サーバー側からホストの AI モデルに「この文章を要約して」と推論を依頼する仕組み（サーバー自身に API キーを持たせずに済む）。
- **Elicitation**（2025-06-18 追加）：サーバーが処理の途中で「この設定値が足りないのでユーザーに入力してもらってください」と構造化フォームで質問を返す仕組み。

### 4. 通信方式（Transports）と 2025〜2026年の主な更新
- **stdio**（標準入出力）：ホストがローカルのサーバープログラムを子プロセスとして起動し、`stdin`（標準入力）と `stdout`（標準出力）で改行区切りの JSON-RPC をやり取りする。ログ出力には必ず `stderr`（標準エラー出力）を使う（`stdout` に普通の文字を出すと通信が壊れるため）。
- **Streamable HTTP**（2025-03-26 で旧 HTTP+SSE を置換）：リモートサーバー向けの通信方式。単一の HTTP エンドポイント（例：`/mcp`）に対する POST / GET で通信し、必要に応じてストリーミング応答も返せる。
- **OAuth 2.1 認可**（2025-06-18 / 2025-11-25 強化）：リモート MCP サーバーの認証・認可を OAuth 2.1（PKCE 必須、Protected Resource Metadata 等）として標準化。
- **ステートレス運用の改善**（2026年）：クラウドのロードバランサー配下でスケールしやすいよう、セッション状態を引きずらないリクエスト処理や Multi Round-Trip の仕組みが整理された。

## 原文引用（短く）

> "Tools are designed to be model-controlled, meaning that the language model can discover and invoke tools automatically based on the user's request."

> "Resources are application-driven: the host application decides how to incorporate context, whether through explicit user selection or automatic heuristics."

## 注意点

- 仕様上は Tools・Resources・Prompts の3本柱だが、実際の AI エージェント製品では **Tools の対応が最も進んでおり、Resources や Prompts の扱いはホスト製品によって差がある**（[07](07_claude-code_mcp-docs.md)、[08](08_vscode-copilot_mcp-docs.md) 参照）。
