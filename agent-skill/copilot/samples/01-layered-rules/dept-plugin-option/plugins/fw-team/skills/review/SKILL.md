# 制御ソフト課のレビュー（プラグイン版）

> サンプル。VS Code ではプラグイン名が前に付き `/fw-team:review` として呼べる。
> Copilot CLI はスキルを `name` で重複排除し、同名ならプロジェクト・個人のスキルが優先される（プラグインは上書きできない）。
> 部署どうしで名前が重なりそうなら、`name` 自体を `fw-review` のように部署名から始めておくと安全。

1. 差分のうち `firmware/` の変更だけを対象にする。
2. タイミング・割り込み禁止区間・共有変数・単位の 4 観点で、指摘を「場所・リスク・直し方」の 1 行にする。
