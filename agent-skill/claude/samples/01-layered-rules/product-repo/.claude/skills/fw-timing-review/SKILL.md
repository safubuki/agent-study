# firmware タイミングレビュー（部署層：制御ソフト課）

`paths` により、firmware/ のファイルを触っているときだけ自動発火の候補になる。
app/ の画面文言の「レビューして」には反応しない。

## 観点（この順に見る）

1. 1 ms 周期の処理に足した処理の最悪実行時間。予算表は [references/timing-budget.md](references/timing-budget.md)。
2. 割り込み禁止区間の長さ（50 µs を超えたら指摘）。
3. 割り込みと本体で共有する変数の保護（`volatile` だけでは不十分な場合）。

## 出力

指摘ごとに「場所・リスク・直し方」を 1 行で。問題が無い観点は「問題なし」と 1 語で済ませる。

## 落とし穴

- `motor_update()` は 1 ms 割り込みから直接呼ばれている。名前から本体ループの関数に見えるので見落としやすい。
