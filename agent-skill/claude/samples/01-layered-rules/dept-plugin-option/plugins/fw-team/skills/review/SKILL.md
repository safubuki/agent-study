# 制御ソフト課のレビュー（プラグイン版）

> サンプル。プラグインのスキルは `/fw-team:review` という名前空間つきの名前になる。
> アプリ課が `/app-team:review` を持っていても衝突しない。

1. 差分のうち `firmware/` の変更だけを対象にする。
2. タイミング・割り込み禁止区間・共有変数・単位の 4 観点で、指摘を「場所・リスク・直し方」の 1 行にする。
