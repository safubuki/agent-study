3. スキル（スキルごとの横棒グラフ。画面に入ったときに伸びるアニメーション）

5. 連絡先（メール・SNS のダミーリンク）

## 見た目と動き・技術規約（厳守）

- 少しオシャレで落ち着いた雰囲気（例：深い緑と生成り色、余白多め）
- ライト／ダークモードの切り替えボタン
- `<html lang="ja">` と `<meta name="viewport" ...>` を必ず入れる
- セマンティックタグ（`<header>`, `<main>`, `<footer>`）をすべて使う
- 配色は `:root` に CSS カスタムプロパティ（`--` で始まる変数）として定義して使う
- スマートフォン幅（〜480px）でも崩れないよう `@media` クエリを入れる
- ナビやテーマ切替ボタンにはアクセシビリティ用の `aria-label="..."` を付ける
- **禁止事項**：
  - 外部 URL（`http://` / `https://`）の `<script>`, `<link>`, `<img>`（Google Fonts や外部 CDN を含む）は一切使わない
  - HTML タグに直接 `style="..."`（インラインスタイル）を書かない（すべて `<style>` 内のクラスにする）
