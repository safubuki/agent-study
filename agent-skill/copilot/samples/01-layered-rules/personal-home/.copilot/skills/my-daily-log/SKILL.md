# 作業日誌（個人層）

> サンプル。実際は `~/.copilot/skills/my-daily-log/` に置く。
> Copilot CLI では同じ名前のスキルは「プロジェクト ＞ 個人 ＞ プラグイン」の順で先に見つかった方が使われる。
> 共有スキルと名前を重ねると、個人のものは使われない（Claude Code とは逆の順なので注意）。

1. 日誌ファイル `~/.copilot/skills/my-daily-log/log.md` の末尾に `- YYYY-MM-DD: <1 行>` を追記する（無ければ作る）。
2. 「週のふりかえり」と言われたら、直近 7 日分を読み、できたこと・詰まったこと・来週やることを 3 行で返す。
